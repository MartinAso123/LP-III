# Ejercicios de la Práctica N.° 03 - SOLID

Cada ejercicio está en una carpeta independiente y contiene un archivo `Main.java`.

## Cómo ejecutarlos en Visual Studio Code

1. Abre esta carpeta completa en Visual Studio Code.
2. Instala **Extension Pack for Java** si todavía no la tienes.
3. Entra a la carpeta del ejercicio que quieras revisar.
4. Abre `Main.java`.
5. Presiona el botón **Run** que aparece sobre el método `main`.

También puedes usar la terminal dentro de cada carpeta:

```bash
javac Main.java
java Main
```

## Contenido

- `Ejercicio_01_SRP`: separa los datos del empleado y el cálculo del pago.
- `Ejercicio_02_OCP`: permite añadir nuevas formas sin modificar las existentes.
- `Ejercicio_03_LSP`: utiliza coche y bicicleta mediante la clase base Vehiculo.
- `Ejercicio_04_ISP`: separa las funciones de imprimir y escanear.
